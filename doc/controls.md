# Controls

### Camera Movement
* **W** - Move Forward
* **S** - Move Backward
* **A** - Move Left
* **D** - Move Right
* **Space** - Move Up
* **-** - Move Down

### Mouse & Navigation
* **Right Click (Hold) + Mouse** - Look Around (Locks cursor to navigate viewport)
* **Scroll Wheel** - Zoom In / Out

### Terrain Sculpting / Brush
* **Left Click** - Apply Active Brush
* **1** - Raise / Lower Brush
* **Left Shift + Left Click** - Invert Brush (Lower Terrain)
* **2** - Smooth Brush

* **Hold Q + Scroll Mouse Wheel** - Adjust Brush Size (Radius)
* **Hold E + Scroll Mouse Wheel** - Adjust Brush Strenght

### Render Modes
* **O** - Cycle Render Mode (Solid / Wireframe / Hybrid)

### System
* **Escape** - Exit Application [SOON WILL BE REMOVED]

* **CTRL+Z** - Undo
* **CTRL+Y** - Redo

* **P** - Toggle Fullscreen
